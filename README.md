# 商圏分析ツール（試作）

地図をクリックして候補地を置くと、半径内に住む人口・世帯数・年齢構成・世帯年収（推計）・市場規模の目安を出すツールです。

公開ページ: https://sochiaisas-web.github.io/shoken-tool/

## 使っているデータ
- 人口・世帯：総務省統計局 e-Stat「令和2年国勢調査 250mメッシュ 人口及び世帯」（1次メッシュ5339）
- 世帯年収：総務省統計局「令和5年住宅・土地統計調査」第43-4表、「市区町村別メッシュ・コード一覧」（区・市単位の分布をもとにした推計）
- 1世帯あたり支出：総務省「家計調査」2024年平均（全国・総世帯）
- 地図：地理院タイル（国土地理院）、住所検索：国土地理院 地名検索

数字は公開統計からの概算で、実際の売上を保証するものではありません。
